# STATUS.md

## What was built

A fully static, offline-friendly directory of genuinely free AI tools for
Asdale Dynamics, LLC (credited in the README and LICENSE).

- **Page** (`index.html` + `css/style.css` + `js/app.js`): card grid with a
  search box, six category filter buttons (All / Chat / Image / Writing /
  Study / Voice), a live result counter, an empty-state note, and a footer
  with the no-affiliate policy and not-medical-advice disclaimer.
- **Data** (`data/tools.json`): the single source of truth — 16 tools across
  chat (ChatGPT, Claude, Gemini, Copilot, Perplexity, Ollama-local), image
  (Copilot Image Creator, Craiyon, AUTOMATIC1111 Stable Diffusion local),
  writing (Grammarly, QuillBot), study (NotebookLM, Khanmigo), and voice
  (ElevenLabs, TTSMaker, Whisper-local). Every tool records: what it does,
  what is actually free, honest limits, browser-vs-local access, a
  `verifiedFreeOn` date (2026-10-22) and a `recheckDate` (2027-01-22).
- **Offline fallback** (`data/tools.js`, generated by `scripts/build-data.js`):
  mirrors the JSON so the page still renders when `index.html` is
  double-clicked from disk (`file://`), where `fetch()` is blocked.
- **Tests** (`tests/validate.js`, no dependencies): 475 automated checks —
  required fields, ISO date sanity, whitelisted categories/accounts access,
  https-only URLs, affiliate/tracking-parameter ban (`utm_`, `ref=`, `tag=`,
  …), offline mirror in exact sync, page references and disclaimers, and a
  secret/API-key-shape scan over the repo.
- **README.md** (maintenance runbook: how to add/recheck tools) and
  **LICENSE** (MIT, "Copyright (c) 2026 Asdale Dynamics, LLC").

## How to run it

```bash
# Use: just open it — no server, no install, works offline
xdg-open index.html        # (or double-click index.html)

# Optional local server
python3 -m http.server 8000   # visit http://localhost:8000

# After editing data/tools.json:
node scripts/build-data.js    # regenerate the offline mirror
node tests/validate.js        # run all checks
```

## Known gaps

- Card links to live third-party sites could drift or disappear between
  recheck dates; the test suite checks link *structure* (https, no tracking
  params) but does not probe the live URLs (no network by design).
- Accessibility is good but not audited: keyboard navigation is natural
  (native `input`/`button`), yet no screen-reader session was run.
- XSS-safety relies on `escapeHtml` in `js/app.js`; a DOMPurify-style
  library was deliberately avoided to keep the page dependency-free.
- No deep-linked category states (e.g. `#voice` in the URL) yet.
- New categories require edits in three places (`tools.json`, the filter
  buttons in `index.html`, and `VALID_CATEGORIES` in `js/app.js` and
  `tests/validate.js`) — noted for the next iteration.
